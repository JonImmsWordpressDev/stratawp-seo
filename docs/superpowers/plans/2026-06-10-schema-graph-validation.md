The schema module already self-disables under Yoast/RankMath/AIOSEO (wp_head bail) — graph respects the same bail; AEO + FAQ/takeaways emitters move INTO the graph builder when schema is enabled, but keep their CURRENT independent output when the main module is deferred (preserve today's behavior under Yoast).
